
# SubastaMorasas

### Sistema web de gestión de subastas y ofertas en línea

## Descripción
SubastaMorasas es una aplicación web diseñada para
administrar productos, subastas y ofertas,
facilitando la participación de los usuarios
en procesos de subasta.

## Objetivo
Desarrollar una plataforma web que permita
gestionar de manera organizada los productos,
usuarios y procesos de subastas.

## Tecnologías
- C#
- ASP.NET Core MVC
- MariaDB
- Entity Framework Core
- Pomelo
- HTML5
- CSS3
- Bootstrap
- JavaScript

## Módulos del sistema
- Gestión de usuarios.
- Gestión de productos.
- Administración de subastas.
- Registro de ofertas.
- Consulta de información.

## Primer corte
Implementación del módulo CRUD de productos
con conexión a MariaDB.
